SQLite迁移: MySQL→SQLite + 移除Redis依赖

## 数据库迁移
- Prisma provider: mysql → sqlite
- DATABASE_URL: mysql://... → file:./dev.db
- 移除所有 @db.* 类型注解（VarChar/Text/Decimal/DateTime/Date）
- 12个 Json? 字段 → String?（JSON序列化为字符串存储）
- 12个 enum 字段 → String（含 @default 改为字符串字面量）
- 删除 11 个 enum 块（UserStatus/ClientType/ClientStatus/MatterType/MatterStatus/FeeType/Priority/CommChannel/Direction/TaskStatus/InvoiceStatus）
- 新增 SQLite 迁移: 20260904014908_init_sqlite

## 代码适配
- backend/src/types/api.ts: enum 导入改为字符串常量对象 + 类型别名（保持 XxxType.VALUE 用法兼容）
- 12个 service/controller 文件: enum 导入源从 @prisma/client 改为 ../types/api
- JSON 字段: 写入时 JSON.stringify，读取时 JSON.parse 还原
- authMiddleware/authController: role.permissions 现为 JSON 字符串，读取时先解析
- seed.ts: enum 值改为字符串字面量，JSON 字段改为 JSON.stringify

## Redis 移除
- backend/src/index.ts: 移除 redis 导入和连接逻辑
- backend/package.json: 移除 redis 和 mysql2 依赖
