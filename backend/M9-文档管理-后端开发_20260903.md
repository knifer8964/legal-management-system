## 接口清单（前缀 /api/v1/documents）
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /documents | 列表（分页+筛选 category/clientId/matterId+搜索） |
| GET | /documents/stats | 统计（按分类分组） |
| GET | /documents/:id | 详情 |
| POST | /documents | 创建（元数据，filePath 用传入值） |
| PUT | /documents/:id | 更新（category/tags/description/clientId/matterId） |
| DELETE | /documents/:id | 删除（物理删除） |

## 响应格式
- 成功：`{ success: true, data: ... }`（用 responseUtil 的 success）
- 分页：`{ data: [...], pagination: { total, page, pageSize, totalPages } }`（在 service findAll 返回体中）

## 关键决策
1. Document 模型**无 updatedAt 字段**（只有 createdAt），故 format 中不处理 updatedAt。
2. update 使用 `Prisma.DocumentUncheckedUpdateInput`（而非 DocumentUpdateInput），因为 clientId/matterId 是标量外键，在 Unchecked 变体中才可直接赋值。
3. tags 为 Json 字段：更新时 `data.tags ?? Prisma.JsonNull` 支持置空；创建时 `data.tags ?? undefined` 避免插入非法值。
4. 分页响应沿用了 invoiceService 的模式：service 返回 `{ data, pagination }`，controller 用 `success(res, result)` 整体包裹。
